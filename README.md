# 🌱 EcoTracker - Приложение для экологических привычек

[![Kotlin](https://img.shields.io/badge/Kotlin-1.9.0-blue.svg)](https://kotlinlang.org)
[![Android](https://img.shields.io/badge/Android-API_24+-green.svg)](https://developer.android.com)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Мобильное приложение для формирования и отслеживания экологических привычек с элементами геймификации. Помогает пользователям внедрять устойчивые практики в повседневную жизнь.

## ✨ Особенности

- ✅ **Трекинг привычек** - Создание и мониторинг ежедневных экологических практик
- 🎯 **Геймификация** - Система уровней, очков опыта и достижений
- 📈 **Визуализация прогресса** - Графики и статистика вашего вклада в экологию
- 👥 **Социальные элементы** - Рейтинги и сравнение с друзьями
- 🔔 **Умные напоминания** - Персонализированные уведомления
- 🌍 **Экологическое образование** - Полезные статьи и советы

## 🏗 Архитектура

Проект построен с использованием современных подходов:

### Технологический стек
- **Язык:** Kotlin с корутинами для асинхронности
- **Архитектура:** Clean Architecture + MVVM
- **DI:** Hilt для управления зависимостями
- **Локальная БД:** Room для кэширования
- **Backend:** Firebase (Auth, Firestore, Cloud Messaging)
- **UI:** Jetpack Compose, Navigation Component
- **Сборка:** Gradle Kotlin DSL
